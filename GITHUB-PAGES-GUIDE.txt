EDGE ROLLER ON IPAD - 10 MINUTE GUIDE

A) Put the game online (free, once)
1. On github.com create a new public repository, e.g. "edge-roller-web".
2. Click "Add file" > "Upload files" and drag in EVERYTHING from this folder
   (index.html, sw.js, manifest.webmanifest, three.min.js, the icons folder and the fonts folder).
   Commit the upload.
3. Repository > Settings > Pages > Source: "Deploy from a branch", Branch: main, folder /root. Save.
4. After a minute the page shows your address, like https://YOURNAME.github.io/edge-roller-web/

B) Install on the iPad
1. Open that address in Safari (it must be Safari).
2. Tap the Share button > "Add to Home Screen" > Add.
3. Start the game from the new Edge Roller icon. It runs full screen and works offline after the first load.

Updating later: upload the new index.html (and bump the number in sw.js, e.g. edge-roller-v24) to the same repository.
Note: iPad Safari has no vibration support, so haptics are silent there. Progress is saved on the device.
